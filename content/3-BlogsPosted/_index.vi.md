###  [Blog 1 - Amazon S3 Vectors: Khi S3 học cách lưu trữ và tìm kiếm vector](3.1-Blog1/)
Blog này giới thiệu tính năng mới Amazon S3 Vectors, cho phép lưu trữ và truy vấn trực tiếp vector embeddings trên S3. Bài viết phân tích cấu trúc hoạt động, cơ chế tính phí, các trường hợp sử dụng phù hợp (như RAG và semantic search) cũng như so sánh khi nào nên dùng S3 Vectors thay vì các vector database chuyên dụng.

###  [Blog 2 - Amazon Aurora DSQL: Database SQL phân tán active-active, bỏ hẳn cơ chế khóa truyền thống](3.2-Blog2/)
Blog này phân tích Amazon Aurora DSQL, một cơ sở dữ liệu SQL phân tán serverless hỗ trợ triển khai active-active đa khu vực (multi-region). Bài viết đi sâu vào sự khác biệt cốt lõi khi sử dụng Optimistic Concurrency Control (OCC) thay cho cơ chế khóa truyền thống, những điểm cần lưu ý khi thiết kế ứng dụng và các tình huống áp dụng phù hợp.

###  [Blog 3 - AWS Cost Anomaly Detection: Người gác cổng giúp bạn không bị dính hóa đơn AWS bất ngờ](3.3-Blog3/)
Blog này chia sẻ về AWS Cost Anomaly Detection (CAD), một công cụ miễn phí ứng dụng Machine Learning để giám sát chi phí AWS bất thường. Bài viết hướng dẫn cách phân biệt CAD với AWS Budgets, cách thiết lập các loại Monitor và cảnh báo, cùng những lời khuyên hữu ích để quản lý chi phí cho các tài khoản cá nhân và học tập.
