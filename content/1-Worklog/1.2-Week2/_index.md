### Week 2 Objectives:

* Master basic network architecture on AWS and successfully deploy a Virtual Private Cloud (VPC).
* Understand how to divide Subnets, route network traffic with Route Tables and Internet Gateways.
* Launch, manage, and remotely connect to Amazon EC2 virtual servers.
* Successfully deploy a real-world application environment on EC2.

### Week 2 Achievements:

* Successfully built a Virtual Private Cloud (VPC) network system:
  * Understood how to set up IP ranges and divide them into Subnets.
  * Successfully configured Route Tables and Internet Gateways for inbound/outbound Internet access.

* Mastered network security layers on AWS:
  * Understood and set up Security Groups acting as firewalls to strictly control ports.

* Proficiently launched and operated Amazon EC2 virtual servers:
  * Knew how to choose hardware configurations (Instance type) and operating systems (AMI).
  * Used Key Pairs for secure remote connection (SSH) to Linux servers.

* Successfully deployed real-world applications:
  * Operated basic Linux commands to install a Web Server.
  * Configured the environment independently and got a backend application running in practice.
