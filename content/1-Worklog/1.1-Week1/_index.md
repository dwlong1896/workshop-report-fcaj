### Week 1 Achievements:

* Successfully connected with the members of the First Cloud AI Journey and became familiar with the team's working environment, rules, and regulations.

* Gained a high-level understanding of AWS and its primary service categories, including:
  * Compute
  * Storage
  * Networking
  * Database
  * Security

* Successfully created and configured an AWS Free Tier account.
  * Understood the concepts of Regions and Availability Zones (AZs), and how to choose the most suitable Region based on latency and service availability.
  * Learned the limitations of the AWS Free Tier to avoid unexpected charges.

* Acquired the skills to manage AWS costs using AWS Budgets.
  * Learned how to read and analyze the Billing Dashboard to monitor service usage.
  * Successfully configured Budgets and Cost Alerts to receive email notifications when spending reaches predefined thresholds.

* Understood how to work with AWS Support.
  * Learned the differences and benefits of the available AWS Support Plans.
  * Learned how to create and monitor a Support Case for technical assistance.

* Developed a solid understanding of AWS IAM.
  * Understood the differences and security implications between the Root User and IAM Users.
  * Created IAM Users and Groups for different project roles.
  * Assigned permissions following the Principle of Least Privilege.
  * Created IAM Roles to securely delegate permissions between AWS services.
